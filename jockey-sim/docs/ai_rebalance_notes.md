# AI 再バランス・ノート — 空き進路探索AI の探索結果

AAAロードマップ Phase1a #1 killer「空き進路探索AI」と、Phase3a で必須となる多目的グリッドサーチ
再バランス基盤の検証記録。**手動チューニングではなく機械的探索で結論を出す**（roadmap 査読blocker）。

## 基盤（再利用可能な再バランス・ツールキット）
- `sims/engine_lab.js` — production `engine.js` の派生。空き進路探索AI＋ペース因果を重み `W`
  （clear/wall/slow/cbend/cstr/beside/fin/cout/inertia/rate/contest）でパラメータ化。
- `sims/grid_search.js` — production からベースライン（脚質シェア/勝ちタイム/スタミナ切れ）を実測し、
  それを目標に `W` を座標降下で収束。`npm run grid [evalN]`。
- 多目的: 脚質≥8% / 一脚質≤40% / 1200前有利 / 2000差し追込有利 / 勝ちタイム±2s / スタミナ切れ上限 / 固有≤12.5%。

## 結論（重要）
**貪欲な「毎フレーム全レーン採点→最良へ移動」型の進路探索AIは、現コース幾何では脚質バランスを
両立できない（構造的・重み調整では直らない）。**

理由: クリア進路ボーナス＋コーナーロス回避により全馬がインの空きを奪い合う。前方の逃げ・先行が
先に確保し、後方の差し・追込は内で詰まり、外に出すとロスで罰せられ末脚を出せない。差し・追込に
不可欠な**「後方で脚を溜め、直線で外へ持ち出して末脚を爆発させる戦略的我慢」**を、貪欲な毎フレーム
スコアラーは表現できない。原版AIはこれを**明示的な脚質スクリプト**（差し・追込は勝負所で
`targetLane += dt*0.9` で外へ持ち出す）で実現しており、それがバランスの土台になっている。

## 採用した着地（Phase1）
- **`laneBias`（馬ごとの置き所の癖 ±0.9）** のみ採用＝脚質ごとの平均レーンを変えずに隊列を横へ散らし、
  ユーザー指摘「馬がただ並んで走っている」を視覚的に解消。balance_check 大標本で全✓（コミット b149a6e）。
- フルの貪欲進路探索AIとペース因果は **不採用**（回帰を割るため出荷しない）。

## 次にやるべき正しい設計（Phase3a で実施推奨）
1. **脚質スクリプト（戦略的我慢）を背骨に維持**したまま、gap-seek を「詰まった時の進路選択」に限定する
   オーバーレイ型へ。貪欲な全フレーム最適化はしない。
2. それを `engine_lab.js` の重み化に載せ替え、`grid_search.js` で再収束。
3. **東京府中ジオメトリ移行（Phase3a）では物理全体を再バランスするため、進路AIの再設計はその一括
   再バランスに含めるのが最も効率的**（コース幾何が変われば最適進路も変わる）。
4. grid_search の高速化（毎フレーム全レーン採点が重く N=120 で約7分）。候補レーンの粗化・ブロック時のみ
   評価・seed固定でノイズ低減。
