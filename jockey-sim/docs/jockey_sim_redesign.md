# 蹄音 ジョッキーSLG 全面改修ブループリント
### ― Gallop Racer 研究と再設計 ―

最重要コンセプト：**「最高の騎乗で能力差を覆した」** という達成感。
強い馬に乗るのではなく、**騎手の判断で勝たせる**。アクションではなくシミュレーション。

---

## 1. Gallop Racer の面白さ（研究）

Gallop Racer が「競馬を分かっている人が作った」と感じられる核は、反射神経ではなく**騎手としての判断の連続**にある。本作が継承すべき要素を抽出した：

1. **展開を読む**：出走馬の脚質・人気から「速くなるか/遅くなるか」を予測し、自分の置き所を決める。
2. **位置取りと折り合い**：道中で脚を溜める。行きたがる馬を抑え、good positionを取る。
3. **馬群さばき**：前が壁、内で包まれる、外を回すロス——進路の選択と我慢。
4. **仕掛けどころ**：早すぎれば失速、遅すぎれば届かない。**一発の判断**が勝敗を分ける。
5. **手応えとスタミナの読み**：残り脚を感じながら追い出す。叩き合いの根性。

逆に本作が**捨てる**もの：ムチ連打、スタート反応の twitch、入力速度ゲー。
→ 入力は「少なく・重く」。一つ一つが意味を持つ判断にする。

## 2. 操作の再設計（アクション→判断）

| 旧（アクション） | 新（ジョッキーSLG） |
|---|---|
| GO の瞬間に［スタート］連打＝反射神経 | **自動発走**。出はゲート駐立＝パワー・調子で決まる |
| ［ムチ］連打で加速 | 廃止。代わりに**［仕掛け］→（もう一度で）［全力］**の2段階・一発勝負 |
| ［内］［外］だけ | **［前へ（押し上げ）］［内］［外］**＝位置取りの主導権 |
| ［抑える］ | 継続（折り合い・脚を溜める。仕掛け前のみ） |

新しい騎乗の流れ：**展開を読む → 位置を取り折り合う → 馬群を捌く → 仕掛けどころを決める → 追って全力**。
すべて「いつ・どこで」の判断であり、速く押す競争ではない。

## 3. 追加機能 ― 実装状況

### ✅ フェーズ1（本バージョンで実装済み）

**① レースごとに展開生成 ＋ ⑩展開予測**
出走馬の脚質構成から想定ペースを生成（前に行く馬が多い→ハイ、手薄→スロー）。発走前の**展開予測カード**で読みを提示。

**② ペース概念**
スロー／平均／ハイをリアルタイム判定・表示。ハイは前が苦しく差し有利、スローは前残り——という競馬の力学が成立。

**④ 実況システム**
発走・ペース・隊列・勝負所・直線・ゴール前接戦を、レース展開に反応して実況。臨場感と「今どういう局面か」の理解を補助。

**⑤ 人気とオッズ**
隠れ能力＋固有＋調子で算出。発走前カードと結果画面に人気・単勝オッズを表示。

**⑥ 馬体重と調子**
全馬に馬体重(前走比±)と調子(絶好調/普通/地味/不調)を付与。調子は能力に±数%反映（単独では勝敗を決めない）。

**⑦ 馬群による進路妨害**
前詰まり（前の馬の速度で頭打ち）、包まれ（並走馬がいる側へ動けない＝袋）、コーナーの外ロス。実況・フラッシュで状況を通知。

**達成感の演出**：人気薄で勝つと結果画面に「🏆 能力差を覆した！」を表示。

### ⏳ フェーズ2（次に実装を推奨）― キャリア／育成の骨格

**③ 騎手能力成長**
騎手ステータス（スタート／折り合い／馬群さばき／追い）。レースごとにXP獲得→レベルアップ。騎手スキルがプレイヤー馬の各処理を底上げ（最大でも±10%程度に抑え「腕＞馬」を成立させつつ過剰にしない）。

**⑧ 賞金とキャリアモード**
着順に応じた賞金。累計獲得賞金・勝利数・連対率を記録。1開催＝数レースを連戦する「シーズン」。

**⑨ 重賞レース**
G3→G2→G1の格。賞金・出走馬の能力・人気の堅さが格で変化。G1制覇を目標に。

**⑩ 年間スケジュール**
クラシック/古馬/距離別のローテーション表。騎乗依頼（複数の馬から選んで乗る＝どの馬で勝つかも戦略）。

**専用 出馬表画面**：現在は発走前カードで簡易表示。フェーズ2で全12頭の一覧（馬番・馬名・脚質・人気・馬体重・調子・近走）を独立画面化。

**永続化**：`window.storage` でキャリア進行を保存（フォールバックでセッション内保持）。

**複数コース**：高速馬場／タフな馬場、コーナー半径違い。固有「東京巧者」等のコース適性を有効化。

## 4. 設計上の配慮（フェーズ2を載せやすく）

- 物理エンジン（ペース→スタミナ→末脚、馬群、コーナー、固有、馬場、距離適性、調子）は**完成済みの土台**。フェーズ2はこの上に**メタ層（賞金・育成・日程）**を被せるだけ。
- 馬＝データ（stats/style/ability/coat/condition/aptDist）とロジックが分離 → 育成・血統・厩舎は data 編集で載る。
- レース結果は通過時刻ベース → オンライン対戦・ランキングへ流用可能。
- 騎手スキルは「プレイヤー処理の補正値」として実装 → 成長要素を足しても物理は不変。

## 6. 実装優先順位（次の一手）

1. **騎手成長＋賞金（③⑧）** ― キャリアの体験を最短で立ち上げ、「腕で勝つ→強くなる」のループを完成。
2. **重賞＋年間スケジュール（⑨⑩）** ― G1という長期目標と、騎乗依頼の戦略性。
3. **専用 出馬表画面＋永続化** ― SLGとしての情報量と継続性。
4. **複数コース＋演出強化**（直線カメラ寄り／接戦スロー／写真判定）。
